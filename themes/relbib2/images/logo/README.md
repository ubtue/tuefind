EPS files usually look very bad in the preview, but that's because there is an embedded thumbnail being created.
Make sure you open the generated EPS via Inkscape or another program and try to print it for quality check!
When generating an EPS, Font Embedding will usually go wrong, which means you should convert the Text into Paths before export!
Keep original file before converting to paths, else you can't edit anymore!
